# Projeto de atividade 3 - Classes - Programação Orientada a Objetos 2
[![NPM](https://img.shields.io/npm/l/react)](https://github.com/Samyr-Dev/LAB03_Vetores/blob/main/LICENSE) 

# Sobre o projeto

O objetivo deste projeto foi implementar construtores **com e sem parâmetros** nas seguintes classes:  
- **Aluno**  
- **Turma**  
- **Biblioteca**  
- **Empresa**  
- **Estoque**  

Também foram implementados métodos, estruturas de comparação e contadores para utilização correta dos atributos.  

Mais do que reforçar a teoria, o projeto busca proporcionar um ambiente **prático de aprendizado**, permitindo aplicar os conceitos em situações reais e consolidar o conhecimento de forma efetiva.
